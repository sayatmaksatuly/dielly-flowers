О создании сайта (Colophon)

Добро пожаловать на страницу Colophon. Этот сайт был разработан в рамках первого задания (Assignment 1) по курсу Web Technologies. Нашей главной целью было создание структурированного, доступного и семантически правильного веб-сайта с использованием исключительно чистого HTML5, без применения CSS, JavaScript или готовых визуальных шаблонов.

Проект выполнен в команде из двух человек: Саят Максатулы и Расул Тажгулов. Мы разделили обязанности поровну. Саят отвечал за настройку репозитория, страницу с формой заказа (order.html), каталог цветов со сложной семантической таблицей цен (flowers.html) и данную страницу отчета (colophon.html). Расул взял на себя разработку главной страницы (index.html), страницы с историей магазина (about.html) и каталога женских сумок (bags.html).

Для контента мы выбрали реальный локальный бизнес — магазин цветов и аксессуаров «Dielly», расположенный в Астане на проспекте Аль-Фараби. Поскольку владельцем бизнеса является родственник одного из участников команды, мы смогли лично посетить точку, сделать авторские фотографии товаров и витрины, зафиксировать актуальный прайс-лист и получить подлинную цитату владельца для главной страницы. Это обеспечило максимальную достоверность и аутентичность контента.

В процессе разработки мы строго придерживались стандартов W3C. Мы использовали семантические теги header, nav, main и footer на каждой странице для правильной структуры. Для обеспечения доступности (accessibility) мы связывали метки label с полями ввода input через атрибуты id и for, а в таблицах использовали атрибут scope для заголовков столбцов и строк. Весь прогресс версионировался с помощью системы Git, обеспечивая прозрачную историю командной разработки.
