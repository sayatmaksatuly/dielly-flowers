# Dielly Flowers & Bags - Web Project

**Course:** Web Technologies - Assignment 3

**Team:** Sayat Maksatuly, Rasul Tazhgulov

**Group:** SE-2533

This is our existing site for a flower and bag shop in Astana. The eight pages are `index.html`, `about.html`, `flowers.html`, `bags.html`, `order.html`, `login.html`, `register.html`, and `colophon.html`.

For Assignment 3 we added Bootstrap 5.3.8 from its CDN. The catalogs use responsive rows, columns and Bootstrap cards; the navigation collapses on smaller screens. Our CSS files keep the Dielly colors and a few image details. The site is responsive for phone, tablet and desktop widths.

To view it locally, open `index.html` in a browser with an internet connection so Bootstrap can load. The order and account forms are examples only: submission is disabled because this static project has no backend.
