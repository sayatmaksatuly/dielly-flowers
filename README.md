## About the Project
This repository contains a 6-page website created for a local flower and bag shop in Astana. 
The main goal of this project is to practice writing clean, semantic, and accessible HTML code. According to the assignment requirements, this website is built using **pure HTML5 only**. There is no CSS and no JavaScript used in this project.

## Website Structure (6 Pages)
1. `index.html` - The main homepage.
2. `about.html` - Information about the shop and its history.
3. `flowers.html` - A catalog of flower bouquets with a price table.
4. `bags.html` - A catalog of exclusive bags using a description list.
5. `order.html` - A semantic order form for delivery or pickup.
6. `colophon.html` - A meta-page explaining how the site was built and our team responsibilities.

## Key Features & Standards Met
* **Strict HTML5:** No styling or scripting applied.
* **Semantic Markup:** Correct usage of tags like `<header>`, `<nav>`, `<main>`, `<footer>`, `<section>`, and `<dl>`.
* **Forms & Accessibility:** The order form uses `<fieldset>` and `<legend>` for logical grouping, and all `<input>` elements are linked with `<label>` tags.
* **Table Accessibility:** The price table includes `<thead>`, `<tbody>`, and uses `scope` attributes for screen reader support.
* **Git Version Control:** The project history shows commits from both authors using a shared repository.

## How to Run
Since this is a static HTML project, you don't need a server to run it. 
Simply download or clone the repository, open the folder, and double-click `index.html` to view the website in any web browser.
