# Dielly Flowers & Bags - Midterm Project

**Course:** Web Technologies - Midterm Project

**Team:** Sayat Maksatuly, Rasul Tazhgulov

**Group:** SE-2533

Dielly Flowers & Bags is a seven-page website for a flower and bag boutique in Astana:

- `index.html`
- `about.html`
- `flowers.html`
- `bags.html`
- `order.html`
- `login.html`
- `register.html`

Bootstrap 5.3.8 provides the responsive layout, utilities, components and navbar behavior. Custom CSS provides the Dielly brand styling. No custom JavaScript is included. Forms contain prepared IDs, feedback areas and result containers for future JavaScript.

To view the site locally, open `index.html` in a browser with an internet connection so Bootstrap can load from its CDN.

## User journeys

### Journey 1 — Find boutique information

**Start:** Homepage

**Steps:** Open About and read the address, opening hours and telephone.

**End:** The visitor has the information needed to plan a visit.

### Journey 2 — Choose a flower and prepare an order

**Start:** Homepage

**Steps:** Open Flowers → compare products → choose a flower → open Order → select the same product → enter delivery details.

**End:** The information is entered and the page clearly states that the order has not yet been sent.

### Journey 3 — Choose a bag and prepare an order

**Start:** Homepage

**Steps:** Open Bags → compare products → choose a bag → open Order → select the same product → enter delivery details.

**End:** The visitor has prepared the order details without requiring registration.
